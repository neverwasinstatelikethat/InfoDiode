# InfoDiode — Фронтенд

Панель управления InfoDiode на базе SvelteKit 5 + Tailwind CSS v4. Обеспечивает мониторинг конвейера обработки видео, просмотр результатов, генерацию QR-кодов и оценку точности.

---

## Технологии

| Технология | Версия | Назначение |
|-----------|--------|-----------|
| SvelteKit | 5 | Фреймворк (runes: $state, $derived, $effect) |
| Tailwind CSS | v4 | Стилизация (CSS-based config через @theme) |
| TypeScript | 5.x | Типизация |
| Vite | 6.x | Сборка и dev-сервер |

---

## Страницы

| Маршрут | Описание |
|---------|----------|
| `/` | Dashboard — обзор системы, статус сервисов |
| `/video` | Загрузка и управление видео |
| `/pipeline` | Управление конвейером обработки, мониторинг прогресса |
| `/calibration` | Калибровка зон сегментации |

| `/qr` | Генерация QR-кодов, наложение на видео |
| `/evaluation` | Метрики оценки, отчёты по точности |

## Архитектура

### Svelte 5 Runes

Проект использует **только Svelte 5 runes**:

```svelte
<script lang="ts">
  // Реактивное состояние
  let pipelineState = $state<PipelineState>('idle');
  
  // Производное состояние
  let isProcessing = $derived(pipelineState === 'processing');
  
  // Побочные эффекты
  $effect(() => {
    console.log('Состояние изменилось:', pipelineState);
  });
</script>
```

### Хранилища данных (`src/lib/stores/`)

| Файл | Описание |
|------|----------|
| `pipeline.svelte.ts` | Состояние конвейера, WebSocket-обновления |
| `metrics.svelte.ts` | Метрики оценки, история точности |

### WebSocket

Реалтайм-обновления прогресса через WebSocket-соединение с бэкендом:

```typescript
// Типы сообщений от сервера
type WSMessage = 
  | { type: 'progress'; video_id: string; progress_pct: number; current_step: string }
  | { type: 'pipeline_complete'; video_id: string; status: string; total_frames: number }
  | { type: 'pipeline_error'; video_id: string; message: string };
```

## Тема оформления

SCADA-тёмная тема с цветовой семантикой:

| Цвет | Семантика SCADA |
|------|----------------|
| Зелёный | Норма, активный параметр |
| Красный | Авария, выход за диапазон |
| Синий | Информационный, неактивный |
| Жёлтый | Предупреждение, близко к границе |
